# 样式重复与复用排查

本轮扫描 `src/styles/` 的全部源样式，按声明内容、选择器、媒体条件及运行表面分别核对。生成目录 `public/assets/css/` 仅通过构建更新。

## 处理结果

| 项目               | 排查前 | 本轮完成后 |
| ------------------ | -----: | ---------: |
| 样式规则           |   2440 |       1978 |
| 相同声明块候选     |    115 |         22 |
| 同条件重复选择器组 |    301 |        191 |

数量是本轮项目快照，不是强制归零指标。单纯字面相同不代表可以移动：简写属性、选择器优先级、媒体条件与 Shadow DOM 都可能影响结果。

## 已清理和复用

- 独立课节分享页去掉误带的工作区、班课编辑和营销样式，保留分享页自身的加载、错误和阅读布局。
- 清除不再由实际模板生成的旧学生目录、旧学情卡片、旧首页统计和内嵌学生面板样式；保留当前学生列表与新学生详情。
- 删除已经被同条件、同选择器规则覆盖的声明；合并没有中间属性冲突的碎片规则。
- 表单字段继承公共的背景、字号与圆角默认值；财务、学生、潜客表格共用基础宽度和边框折叠规则。不同的边框色、间距与字号继续由页面定义。
- 工具栏行布局、固定标题、详情面板、两行摘要和阅读焦点规则统一复用。
- 新增 `reports/shared-theme.css`，供学生报告和课节报告复用重置、卡片、标题与指标标签；各报告继续提供自己的颜色变量和布局。

## 保留的候选

剩余同字面值候选包括首页作用域恢复规则、不同优先级的控件规则、独立阅读主题，以及语义不同但恰好同色的标记。没有将这些候选机械合并到全局，避免改变现有层叠关系。

日程的 `schedule-mark-*` 与班课的 `tone-*` 是运行时拼接的类名，不能按“没有完整字符串”判断为无用样式。

## 验证与后续排查

```sh
npm run styles:audit
node scripts/audit-styles.cjs --json
npm run format:check
npm run build
npm test
```

本轮保持未改版页面及有课日期首页的几何尺寸和实际样式。学生详情在排查期间由另一轮工作更新，保留其新实现，并通过 `tests/browser/student-detail.cjs` 单独验证；不拿旧详情基线回退新功能。

新增公共控件时先查看 `core/components.css` 与基础表格、表单规则；报告公共规则归 `reports/shared-theme.css`。页面只保留布局和确实不同的变体，不再另加历史覆盖样式文件。

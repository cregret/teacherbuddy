# 当前界面约定

本项目使用原生 CSS 与 Material Web 组件，设计变量统一由 `src/styles/core/tokens.css` 管理。布局与控件分别在 `workspace.css`、`components.css` 中维护，页面差异归入 `styles/pages/`。

- 现有浅色工作区、顶部导航、侧栏、班课彩色卡面与阅读主题保持不变。
- 不显示重复的频道大标题、英文眉题、分类口号或页面用途介绍。
- 统计只展示必要指标名称和数值，解释使用对应控件的提示。
- 分组由教师自定义，不通过名称推断授课或归档状态。
- 班课卡片只保留分组、班名、上课时间、授课进度与人数。
- 独立报告样式在独立文档或 Shadow DOM 中隔离；不要把阅读主题叠加到工作区。
- 页面自身负责空态、错误态与窄屏布局，不增加全局历史覆盖样式。

本轮目录整理通过 1440、768、390 像素宽度下的页面样式与几何尺寸比对，基线和实际截图保存在本地忽略目录中。
